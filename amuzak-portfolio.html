Huyhoangjsc Enterprise Platform (HRM & Real-time Chat)

home.huyhoangjsc.com

Contributed to the development and scaling of an enterprise digital governance and internal collaboration platform built on a microservices ecosystem with NestJS and React (TypeScript). The system clearly decouples two key functional engines: heavy-computation Human Resource Management (HRM) and ultra-low-latency real-time chat.

Key Contributions & Architecture:
  • HRM Engine: Configured BullMQ + Redis distributed queues to handle intensive background jobs (timesheet payroll calculations, batch report generation) without blocking the primary event loop; guaranteed ACID transactions in PostgreSQL.
  • Real-time Chat Service: Engineered instant cross-department messaging with WebSocket connections; optimized chat history storage and flexible schemas in MongoDB.
  • Media & Storage: Integrated AWS S3 Pre-signed URLs for high-speed direct document/attachment uploads, eliminating unnecessary bandwidth overhead on backend servers.
  • Constructed a unified, responsive enterprise operations console using React & TypeScript.
